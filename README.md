# Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to understand purchasing patterns, customer segments, product preferences, discounts, subscriptions, and other factors influencing customer spending.

The project uses **Python, SQL, and Power BI** to perform data analysis and create an interactive business dashboard.

## 🎯 Business Problem

The objective is to analyze customer shopping data and identify meaningful patterns that can help businesses understand:

- Customer purchasing behavior
- Product category performance
- Customer demographics
- Subscription behavior
- Discount usage
- Purchase frequency
- Customer spending patterns
- Factors affecting customer purchases

## 🔎 Analysis Workflow

- Loaded the customer shopping dataset

### 2. Data Cleaning

### 3. Exploratory Data Analysis
